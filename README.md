# Orion Syndic

Site web et démo de l'application Orion Syndic, le logiciel de gestion pour syndics de copropriété au Luxembourg.

- `index.html` : le site complet (page d'accueil, inscription, connexion et démo de l'application) en un seul fichier.
- `logo/` : le logo en versions claire, sombre et icône (SVG et PNG).
- `source/` : les fichiers sources et les scripts qui génèrent `index.html` et le logo.

## Statut

Version de démonstration : l'inscription et le paiement sont simulés, et les comptes restent dans le navigateur du visiteur. La version finale nécessite un serveur avec base de données, connexion sécurisée et paiement Stripe.
